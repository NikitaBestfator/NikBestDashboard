# 🧠 NikBest Dashboard

**NikBest Dashboard** — это мощный десктопный командный центр для управления контентом. Всё в одном месте: идеи, планирование, моды, юниты, тексты и аналитика.

---

## 🎯 Возможности

| Модуль | Описание |
| :--- | :--- |
| **📝 Трекер идей** | Добавление, редактирование, удаление, закрепление, архив, фильтры по категориям и статусам, случайная идея |
| **📋 Текст для видео** | Генерация названий и текстов обложек, 7 шаблонов, анализ заголовков, библиотека, избранное |
| **📊 Юниты** | База юнитов из игр (Minecraft, TABS), фильтры по игре и категории, сравнение юнитов |
| **📅 Планировщик видео** | Планирование видео, статусы (в планах, в работе, готово, опубликовано), фильтр по статусу |
| **📦 Моды** | Библиотека модов с категориями, фильтрация, поиск, добавление, удаление |
| **⚡ Команды** | Справочник команд Minecraft с категориями, поиск, копирование в буфер |
| **🔍 Глобальный поиск** | Поиск по всем модулям сразу (идеи, моды, юниты, тексты, план) |
| **⏱️ Таймер записи** | Таймер для записи видео с выбором времени (1–10 минут), звуковые сигналы |
| **⚙️ Настройки** | Путь к данным, перезапуск, экспорт/импорт данных, сброс данных |
| **⌨️ Горячие клавиши** | Быстрое переключение между модулями: `Ctrl+1`..`Ctrl+7` |

---

## 🚀 Технологии

- **.NET 10.0**
- **WPF (Windows Presentation Foundation)**
- **C#**
- **System.Text.Json** — для хранения данных в JSON

---

## 📁 Структура данных


| Файл | Содержимое |
| :--- | :--- |
| `ideas.json` | Идеи для видео |
| `schedule.json` | Планировщик видео |
| `units.json` | Юниты из игр |
| `text_ideas.json` | Заголовки и тексты |
| `mods.json` | Моды |
| `settings.json` | Настройки приложения |

---

## 🛠️ Установка и запуск

### 1. Скачать готовый `.exe`
Перейдите в раздел **Releases** и скачайте последнюю версию:
[NikBest Dashboard Releases](https://github.com/NikitaBestfator/NikBestDashboard/releases)

### 2. Запустить
Распакуйте архив и запустите `NikBestDashboard.exe`.

## Системные требования

Windows 10 / 11 (64-bit)

.NET 10.0 (встроен в .exe, отдельно устанавливать не нужно)
